# Coastal Wellness

A design concept website for Coastal Wellness, a Brevard County, FL group
therapy practice — built with Next.js (App Router), React 19, TypeScript
and Tailwind CSS v4.

## Pages

- `/` — Homepage
- `/team` — Meet Our Team (filterable directory of 17 clinicians)
- `/services` — Services & Specialties (tabbed directory)

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Notes

All clinician names, photos, bios, office addresses, and award copy are
illustrative placeholders for the design concept — replace with real
content (and the real Coastal Wellness logo/brand assets) before
production use.
